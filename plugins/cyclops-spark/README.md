# cyclops-spark

Spark, Claude's living presence for Claude Code in the terminal, driven only by real Claude Code events. It draws as
half-block cells in any true-colour terminal, or as real pixels on kitty and Ghostty. Requires Claude Code 2.1.288 or
later. On surfaces other than the terminal it shows only its glyph and its state line.

Try it from this folder: `claude --plugin-dir .`, then `/spark`. `/spark help` lists every command; the repository
README describes what each state looks like.

## What Spark does on your machine

Spark only draws and plays sounds. This section lists everything she touches, so you can check it before installing.

**Permissions.** Spark does not hook the permission check (`tool.check`) at all: Claude Code alone decides what is
asked, allowed or denied. She never changes a permission mode or setting. Her hooks (`session.start`, `session.end`,
`config.set` for the theme, `tool.call`, `session.compact`, `turn.complete`, `/copy` and the streaming events) pass
straight through with `next(e)` and only watch. When a call you denied comes back denied, she shows it as a quiet
closed gate.

**Programs she starts.**

- `uname -s` and `which` (once per session, only when sound or murmur is on): to find a sound player on Linux.
- `pw-play`, `paplay` or `aplay -q`: to play her own clips from `sounds/`, only when you turn sound or murmur on.
  On macOS Claude Code plays them itself.
- `python3 link/spark_link.py`: the Cyclops Link helper, only while Link is on (off by default; the `link` setting,
  `/spark link on`, or `SPARK_LINK=1`). It is plain, readable Python in this folder.

**Files she writes.** None, unless you turn Link on. With Link on, the helper keeps a small record of Spark's coarse
state (idle, thinking, writing…, counts of calls, and whom she is calling) in `~/.local/state/cyclops-link/` (or
`$XDG_STATE_HOME/cyclops-link`, or `$CYCLOPS_LINK_DIR`), and a private facts file in `~/.local/state/cyclops-spark/`,
created with 0600/0700 permissions. Never prompts, commands, file paths or names. She writes no build, start-up,
settings or instructions file.

**Data out.** Nothing leaves your machine. Spark makes no network requests. The Link record is a local file read only
by Keeper (Codex) and Prism (Antigravity) presences on the same computer, when they have Link on too.
`/spark ask` asks your question through Claude Code's own `model.fork` (the same model and account as your session,
without tools); Spark does not see or store a credential. `SPARK_LINK` is only an on/off switch.

**Generated and binary files.** `hooks/link-marks.js` is generated by `tools/vendor-link-marks.mjs` from the readable
sheets in `link-mark/` (see `link-mark/SOURCE.md`); do not edit it by hand. `sounds/*.wav` are Spark's own synthesised
cues.

## Files

| File | What it is |
| --- | --- |
| `hooks/register.ts` | Wires the host events and the `/spark` command; paints the pane and band. |
| `hooks/core.js` | The state machine, the scene builder and `MAPPING` (the event behind every animation). |
| `hooks/render-raster.js` | Draws a scene as pixels: half-block cells, or RGBA for kitty / Ghostty. Draws Keeper's eye in his slot. |
| `hooks/trace.js` | The labelled replay script (`/spark replay`). |
| `hooks/colour-engine.js` | Infinite Colour / DrawPlayer Colour Language. |
| `sounds/` | The synthesised cues and murmur phrases. |
| `tests/` | `claude plugin test .` |
